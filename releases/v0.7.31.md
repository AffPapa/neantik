# NeAntik 0.7.31 (94)

Direct Distribution · public alpha · macOS 14+ · Apple Silicon

## Что изменилось

- Исправлен разбор пути приложения: обычный запуск из существующего каталога `/private/tmp` больше не отвергается из-за подмены пути средствами Foundation. Отрицательные проверки опасных путей сохранены.
- Исправлена ошибочная остановка транзакции обновления при изменении только `ctime` корневого каталога приложения. Права, ACL, inode, содержимое и все вложенные файлы продолжают проверяться строго.
- В отдельном подписанном QA проверены независимый процесс обновления, подтверждение готовности нового приложения, продолжение в обычный интерфейс, отмена и восстановление при сбоях. Это основа updater; автоматическая установка обновлений в публичной сборке пока выключена.

## Реальные проверки

- 1254 Swift-теста / 144 набора: PASS. Отдельные регрессии пути запуска и сохранности каталога приложения проверены положительными и отрицательными контролями.
- Подписанное изолированное QA: создание/сохранение профиля клавиатурой, запуск и остановка headed Chromium, отмена создания, справка и сохранение профиля после перезапуска.
- Точный кандидат: Developer ID, Apple Accepted ZIP/DMG, stapling, Gatekeeper, headed runtime и MCP PASS. Независимо скачанные ZIP/DMG совпали по хэшам и прошли native gates. Скачанное приложение прошло свежие headed и MCP проверки.

## Сохранено

Chromium 156.0.8078.12 без пересборки; прежний Developer ID сертификат. Копия BrowserData и восстановление исходного профиля, режим предыдущих вкладок, существующие MCP-инструменты и центр расширений сохранены.

## Ограничения

Public alpha. Автоматический updater и полный CRX installer не включены; continuous browser-route и production HTTPS relay ещё не квалифицированы. Backup не переносит OS-encrypted секреты между Mac. Проверки проводились на ARM64/macOS27beta и не доказывают совместимость со всеми Mac. Нет обещания анонимности, обхода CAPTCHA или правил сайтов. Сканирование известных форматов секретов не доказывает отсутствие любого возможного секрета.

## Откат

Предыдущий immutable v0.7.30 сохраняется на GitHub. Эта manager-версия не меняет runtime/схему данных или identity профилей.

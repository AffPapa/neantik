# NeAntik 0.7.17 (80)

6 октября 2026 года. Direct Distribution для Apple Silicon, macOS 14+.

- Импорт изменения папок/тегов теперь меняет `mutationRevision`; устаревшая metadata Undo из другого окна отклоняется.
- В редакторе профиля сеть расположена перед оформлением. Ввод прокси имеет явные режимы строки и полей; неприменённая строка показывает действие у заголовка формы.
- Проверка и изменение прокси доступны прямо в карточке профиля. Библиотека адаптирована к компактному окну; удаление шаблона/фильтра и очистка журнала требуют подтверждения.
- Chromium 154.0.8037.93 сохранён без пересборки.

Проверки: 51 targeted и 683 полных Swift-теста; изолированный Dev.app (создание, редактирование, синтетический прокси, отмена и подтверждение удаления шаблона, запуск/остановка профиля, быстрые команды, видимая ошибка сохранения); A → B → A и Device Memory JS/HTTP на точном кандидате; runtime source snapshot, Developer ID, Apple notarization, stapling, Gatekeeper ZIP/DMG. Черновые и публичные GitHub ZIP/DMG скачаны и побайтно сверены с локальными файлами. Реальные профили не изменялись.

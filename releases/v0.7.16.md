# NeAntik 0.7.16 (79) — надёжная проверка прокси

Проверка прокси сверяет выходной IP, страну и часовой пояс по двум независимым сервисам. При отказе одного сервиса доступен резервный источник; противоречивые ответы не принимаются. Лимит IP-сервиса не объявляется поломкой прокси. Результат проверки относится к моменту измерения и не доказывает сетевой маршрут Chromium.

Форма профиля яснее показывает протокол и порт, поддерживает вставку распространённых строк прокси и размещается в основной области компактного окна.

Перед публикацией обязательны точные проверки кандидата: Developer ID, notarization, stapling, Gatekeeper, runtime provenance и скачанные публичные ZIP/DMG. Пока они не пройдены, эта запись описывает кандидат, а не опубликованный выпуск.

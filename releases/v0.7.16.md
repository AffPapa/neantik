# NeAntik 0.7.16 (79)

5 октября 2026 года. Direct Distribution для Apple Silicon, macOS 14+.

- Проверка прокси сверяет ответы ipwho.is и FreeIPAPI по выходному IP, стране и часовому поясу; при недоступности сервиса используется прежний резервный источник. Противоречивые ответы не принимаются.
- Лимит IP-сервиса не объявляется неисправностью прокси. Результат curl относится к моменту измерения и не подтверждает маршрут Chromium.
- Тип и порт прокси, варианты вставки и результат проверки стали яснее; редактор занимает основную область компактного окна.
- Chromium 154.0.8037.93 сохранён без пересборки.

Проверки точного кандидата: 682 Swift-теста; 33 пользовательских HTTP-прокси через два IP-сервиса; один авторизованный HTTP-маршрут на существующем Chromium; синтетические Device Memory и A → B → A; Developer ID, Apple notarization, stapling, Gatekeeper и runtime provenance на ZIP/DMG. Скачанные из черновика GitHub ZIP и DMG байт в байт совпали с локальными перед открытием релиза.

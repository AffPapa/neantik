# NeAntik 0.8.12 (124)

Public alpha для macOS 14+ / Apple Silicon. Chromium 156.0.8078.12.

## Что изменилось

- Исправлена инвентаризация вложенных файлов Chromium Framework в проверке целостности приложения. Проверка теперь учитывает весь framework и отклоняет отсутствующие или изменённые файлы.
- Добавлено безопасное завершение служебного аудита: тестовый ключ можно удалить отдельной проверяемой операцией без повторного полного аудита браузера. Операция проверяет точный кандидат и не открывает пользовательские профили.
- Сохранены прежний Chromium, сертификат Developer ID, данные профилей и предыдущий релиз для отката.

## Проверки этого кандидата

- Swift: 1541 reported tests / 179 suites, 76 секунд; часть native-тестов явно пропущена. Полный Python-прогон выявил одну ошибку стенда; после исправления соответствующий модуль прошёл 12 тестов. Первоначальный прогон не обозначается полностью успешным.
- Точный подписанный менеджер: GUI и headed fingerprint; MCP — 18 инструментов управления и 7 просмотра, 20 проверок metadata и отказов. Эти MCP-проверки не доказывают сетевой маршрут браузера.
- Настоящее обновление 0.8.11 (122) → 0.8.12 (124): подтверждены новые байты приложения, перезапуск и сохранение двух синтетических профилей. При контролируемом отказе до подтверждения запуска восстановились точные байты 0.8.11 и те же профили. Рабочие профили пользователя не использовались.
- Developer ID, Apple notarization, stapling, Gatekeeper и проверка публичного содержимого ZIP. Контрольные суммы ниже относятся к неизменяемым файлам этого выпуска.

## Ограничения

Это public alpha; полная программа 1.0 и проверка всех моделей Mac ещё не завершены. Физический проход VoiceOver не заявляется проверенным. WebKit preview работает через прямое подключение; прокси, расширения, полный backup, камера/микрофон и запуск через stdio MCP в этом режиме не доступны. Safe Browsing остаётся отключённым. Гарантии анонимности, обхода CAPTCHA и правил сайтов нет.

Проверка обновления относится к metadata синтетических профилей; перенос свежих cookies или OS-encrypted passwords между Mac не заявляется. Проверка authenticated HTTPS upstream с сертификатом, которому доверяет macOS, остаётся отложенной до появления тестового сервера. Один ранний отказ MCP не сохранил ответ до assertion и остаётся необъяснённым; последующий инструментированный прогон прошёл, исправление продукта для этого отказа не заявляется.

Предыдущая [0.8.11](https://github.com/AffPapa/neantik/releases/tag/v0.8.11) сохранена для отката. Скачайте DMG или ZIP; Code → Download ZIP скачивает исходники, а не приложение.

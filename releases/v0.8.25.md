# NeAntik 0.8.25 (137)

Исправление ручной диагностики прокси. Бесплатная public alpha для Mac с Apple Silicon, macOS 14+.

## Что изменилось

- Проверка по своему HTTPS-адресу больше не должна показывать успешный результат для уже изменённых настроек профиля, пароля или адреса диагностики. Перед показом результата приложение повторно сверяет настройки.
- При ошибке подготовки тестовой подписи причина сбоя и результат очистки сохраняются отдельно. Неопределённый результат не запускает повторное создание или удаление ключа автоматически.

## Проверено

Для этого кандидата выполнены исходные тесты с отрицательными контролями, оконная проверка диагностики на отдельном стенде и headed-проверка точного подписанного приложения. Ограничения среды первого полного тестового прогона сохранены в отчёте; повторены только затронутые наборы.

## Ограничения

WebKit остаётся preview. Прокси в production WebKit пока заблокирован: надёжная сетевая изоляция ещё не подтверждена. Полный backup WebKit также не заявлен. Проверка своего адреса использует curl и не доказывает маршрут открытого браузера.

Chromium 156.0.8078.12 сохранён без пересборки. Версия 1.0 пока не готова. Квалификация выполнена на одном Mac ARM64; проверка всех сочетаний устройств и macOS не заявлена.

Схема профилей не менялась. Предыдущая 0.8.24 сохранена для отката. Обновление browser.free выполняется отдельно; актуальные файлы этой версии находятся в assets данного релиза.

# NeAntik 0.8.11 (122)

Public alpha для macOS 14+ / Apple Silicon. Chromium 156.0.8078.12.

## Изменения

- Значок успешной проверки прокси обновляется со временем: старый результат больше не остаётся зелёным бесконечно. Новая проверка не запускается сама.
- Исправлена синхронизация внутренней проверки Client Hints: сначала завершается ответ с Accept-CH, затем сравниваются запросы браузера и JavaScript.
- Упрощён повторный запуск разработческой сборки и исправлены проверки опубликованных ZIP/DMG в инструментах проекта.

## Проверки

1534 Swift-теста / 178 наборов и 1367 Python-тестов; отдельные native-тесты могут быть пропущены явно. Точный подписанный кандидат: headed fingerprint, Device Memory и MCP (18 инструментов управления, 7 просмотра). Developer ID, Apple notarization, stapling и Gatekeeper для ZIP/DMG.

## Ограничения

Полная программа 1.0 и проверка всех моделей Mac остаются в работе. Физический проход VoiceOver не заявляется проверенным. WebKit preview: прямое подключение; прокси, расширения, полный backup и доступ к камере/микрофону не заявляются. Safe Browsing остаётся отключённым. Нет гарантии анонимности, обхода CAPTCHA или правил сайтов. Предыдущая 0.8.10 сохранена для отката.

Для обновления можно скачать DMG/ZIP вручную. Native переход 0.8.10→0.8.11: проверены установка, подтверждение запуска и сохранение двух синтетических профилей. При намеренном отказе нового процесса до подтверждения восстановилась 0.8.10. Это проверка metadata и механизма установки; перенос паролей между Mac не заявляется.

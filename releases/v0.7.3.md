# NeAntik 0.7.3 (66)

Direct public alpha for Apple Silicon Macs running macOS 14 or later.

Public artifacts:

- [GitHub release](https://github.com/AffPapa/neantik/releases/tag/v0.7.3)
- `NeAntik-0.7.3-arm64-notarized.zip`
- `NeAntik-0.7.3-arm64-notarized.dmg`
- SHA-256 sidecars for both artifacts

## Runtime boundary

This release keeps the previously shipped Chromium runtime and does not
represent a Chromium rebuild. The published runtime is Chromium
`153.0.8010.36`; the current repository security baseline is
`153.0.8010.52` or newer. The release must therefore be treated as a public
alpha with an explicit security limitation, not as proof that the runtime is
current against the latest Stable security baseline.

Apple signing, notarization, stapling, and Gatekeeper validation establish
artifact provenance and launch trust. They do not replace missing Chromium
security updates.

## Scope

The release is a local-first profile manager for Apple Silicon. It provides
separate profile data, local Keychain-backed proxy credentials, profile locks,
and diagnostic fingerprint checks. It does not promise anonymity,
undetectability, or bypasses for CAPTCHA, bans, anti-fraud systems, or third-
party rules.

This file records the already published public release. It is not approval for
the current working tree or for a new release candidate.

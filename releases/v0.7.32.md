# NeAntik 0.7.32 (95)

Direct Distribution · public alpha · macOS 14+ · Apple Silicon

## Что изменилось

- HTTPS-прокси с авторизацией теперь подключается через отдельный локальный relay профиля, как HTTP и SOCKS5. Сохранённые данные передаются без повторного окна входа Chromium.
- Для HTTPS сначала macOS проверяет сертификат прокси. При ошибке сертификата пароль не отправляется; перехода на HTTP или прямое подключение нет.
- Обновлены пояснения сети в редакторе, справке и документации MCP.
- Исправлена зависимость тестов собственного процесса updater от посторонних процессов Mac. Строгий отказ production updater при неизвестном живом процессе сохранён; добавлены реальные отрицательные контроли удалённого executable и поколения PID.

## Проверки и границы

1317 Swift-тестов / 151 набор: PASS. Отдельно проверены macOS default TLS и обмен данными без частного CA; 9 локальных TLS/CONNECT сценариев, включая неправильное имя, просрочку, чужой CA, отсутствующий intermediate, plaintext, отмену и TLS-обрыв.

Подписанный headed QA прошёл обычный выбор HTTPS relay, открытие HTTPS-страницы Chromium, повторное принятие той же сессии manager и ошибки после обрыва upstream без Direct fallback. Это ограниченное измерение конкретной сессии. Полный authenticated CONNECT через публичный OS-trusted HTTPS-прокси отдельно не измерен; универсальный DNS/route verdict не заявляется.

Chromium 156.0.8078.12 не пересобирался. Схема, identity профилей и ранее опубликованные assets не меняются. Используется прежний Developer ID сертификат.

## Ограничения

Public alpha. Публичный атомарный updater выключен; полный CRX installer ещё не квалифицирован. Backup восстанавливает BrowserData исходного закрытого профиля на том же Mac с исходной Связкой ключей и runtime; перенос авторизации между Mac не обещается. Safe Browsing выключен. Проверки ARM64/macOS27beta не доказывают работу на каждом Mac. Нет обещания универсального обхода CAPTCHA или правил сайтов.

## Откат

Предыдущий неизменяемый v0.7.31 сохраняется на GitHub. Публикация только GitHub и browser.free; affpapa.org пользователь обновляет самостоятельно.

Статус: candidate; подпись, notarization и публичные байты добавляются после выполнения release gates.

# NeAntik 0.8.2 (113)

Исправление карточки прокси.

Исправлено падение менеджера при выборе или сохранении профиля с прокси: средства доступности вызывали рекурсивное чтение текста карточки. Карточка получила отдельное доступное описание; кнопки проверки, копирования и изменения прокси сохранены.

Также добавлен быстрый локальный цикл разработки: общие кэши Swift, выбранные наборы тестов за один запуск, контроль пустой выборки и конфликтующих запусков. Это ускоряет работу разработчика, не меняя правила проверки релиза.

## Проверено

- 1 477 Swift-тестов в 168 наборах, последовательный запуск jobs=2.
- Точный подписанный ZIP: выбор, редактирование и сохранение прокси без падения; штатный запуск профиля через authenticated HTTP relay; HTTP и HTTPS destination, отказ upstream без наблюдаемого Direct fallback; отдельный Direct negative control.
- Developer ID, Apple notarization, stapling, Gatekeeper; ZIP и DMG. Использован прежний сертификат.
- Chromium 156.0.8078.12 сохранён; новая headed A→B→A квалификация точного кандидата.

## Границы

Это public alpha, не завершённая 1.0. WebKit остаётся экспериментальным системным движком в отдельном окне NeAntik: direct only, без вкладок, прокси, расширений и полного BrowserData backup. Для этих операций выбирайте Chromium.

HTTP/HTTPS проверки относятся к конкретным контролируемым запросам, не доказывают всю DNS/UDP изоляцию. HTTPS destination не заменяет проверку authenticated HTTPS upstream с публично доверенным сертификатом; этот сценарий отложен по согласованию.

Backup возвращает исходный закрытый Chromium профиль на том же Mac с исходной Keychain; перенос системных секретов между Mac не заявляется. Механизм updater и rollback проверен на подписанной паре 0.7.46→0.7.47; установка пары 0.8.1→0.8.2 отдельно не квалифицирована.

Safe Browsing остаётся отключённым. Нет гарантии анонимности, обхода CAPTCHA или правил сайтов. Проверки на ARM64/macOS27 не заменяют проверку каждого Mac. Физический проход VoiceOver не заявляется проверенным.

## Откат

Предыдущая 0.8.1 сохранена с неизменными файлами. Metadata schema2 не поддерживает downgrade к старым менеджерам; сначала сохраните отдельную копию данных. Обновление не меняет identity профилей.

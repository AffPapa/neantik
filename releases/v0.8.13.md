# NeAntik 0.8.13 (125)

## Что изменилось

- Исправлен ввод SOCKS5: лишние пробелы вокруг логина больше не мешают проверке, пробелы внутри пароля сохраняются.
- Можно вводить стартовую страницу с портом: `example.com:8443`, `localhost:8080`, `[::1]:8080`.
- WebKit соблюдает общий интервал между запусками; неудачная попытка не занимает слот.
- MCP сообщает возможности выбранного движка. AI-клиент видит, какие действия доступны для Chromium и WebKit.
- Настройки языка и часового пояса Chromium больше не игнорируются при запуске WebKit: приложение объясняет несовместимость.
- Исправлены текст отказа при неизвестном состоянии процесса и проверка температуры перед запуском.

## Совместимость

Apple Silicon, macOS 14+. Chromium **156.0.8078.12**. Системный WebKit остаётся preview: отдельные данные сайтов, системная идентичность macOS; без полной подмены fingerprint, прокси, расширений, запуска через MCP и полного BrowserData backup.

Public alpha. Изоляция профилей не гарантирует анонимность или обход правил сайтов. Safe Browsing отключён. Предыдущая версия сохранена для отката.

Контрольные суммы ZIP и DMG — в файлах `.sha256` рядом с загрузками.

## Проверки

Проверены подпись точного кандидата, изолированный headed-прогон Chromium и MCP (18 инструментов управления, 7 просмотра). Установщик сохраняет прежние подписанные модули обновления. Контрольные суммы и итоговые проверки публикации указаны в отчёте релиза.

## Ограничения проверки

Safe Browsing остаётся отключённым. Физический проход VoiceOver не заявляется проверенным. Полная production-квалификация аппаратных когорт и программа 1.0 остаются открытыми. Нативные проверки выполнялись на изолированных тестовых профилях; перенос секретов между разными Mac не заявляется.

# NeAntik 0.3.22 (25)

Direct Distribution release для Mac с Apple Silicon.

## Что изменилось

- Основной экран стал list-first workspace с адаптивными строками и нативным
  inspector.
- Добавлены папки, теги, заметки, структурированный поиск и безопасные
  пакетные действия.
- Запуск разделён на runtime, storage, proxy, consistency и process stages;
  локальный Центр готовности объясняет проблемы без утечки секретов.
- Встроен ARM64 Chromium 152.0.7977.64 без telemetry и фоновых служб.

## Проверка выпуска

ZIP и DMG подписаны Developer ID, приняты Apple Notary Service, stapled и
проверены Gatekeeper. Точный tag commit:

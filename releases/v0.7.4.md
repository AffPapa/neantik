# NeAntik 0.7.4 (67)

Публичный Direct public-alpha релиз для Mac с Apple Silicon.

## Артефакт

- [GitHub release](https://github.com/AffPapa/neantik/releases/tag/v0.7.4)
- `NeAntik-0.7.4-arm64-notarized.zip`
- SHA-256: `77144117eafad98929fef37037a32f24fa37e8e932facd81e4c87ecc3b48499f`

## Runtime

В релизе использован ранее квалифицированный Chromium `153.0.8010.52`,
ARM64 и Metal. Chromium в рамках этого manager-релиза не пересобирался.

## Проверка

Архив подписан Developer ID, принят Apple notarization, проверен stapling и
Gatekeeper, а опубликованный GitHub asset повторно совпадает с локальным
SHA-256. Релиз остаётся public-alpha и не обещает универсальный обход
антифрод-систем, CAPTCHA, банов или правил сторонних сайтов.

# NeAntik 0.3.12 (15)

First open-source public-alpha release of NeAntik Direct for Apple Silicon.

## Download

Download `NeAntik-0.3.12-arm64-notarized.zip` from the assets below.

SHA-256:

```text
b8a791056a8857339e1a52e48a81181f49525d2737cf985886b0b1aa05b8fc73
```

Requires macOS 14 or newer and an Apple Silicon Mac.

## Included

- native SwiftUI profile manager;
- embedded Chromium `150.0.7871.186`, ARM64, Metal;
- persistent and isolated browser data per profile;
- Direct, HTTP, HTTPS, and unauthenticated SOCKS5 proxy modes;
- proxy passwords stored in macOS Keychain;
- deterministic public-alpha profile-surface separation;
- local A → B → A fingerprint stability check;
- Direct telemetry disabled.

## Important limitation

NeAntik does not claim complete anonymity or undetectability. Strict production
coherence across every fingerprint, network, TLS, font, locale, timezone, and
proxy-geography surface remains incomplete.

The project is intended for privacy, separated work sessions, development, and
QA. It is not intended for bypassing CAPTCHAs, bans, anti-fraud systems, or
third-party platform rules.

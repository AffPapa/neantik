# NeAntik 0.3.21 (24)

Direct Distribution release для Mac с Apple Silicon.

## Что изменилось

- Диагностика среды ведёт к реальному разделу, а официальная переустановка
  сохраняет данные профилей.
- Заметка видна сразу при создании и всегда отображается в карточке профиля.
- Установленное приложение уменьшено примерно на 125 МиБ безопасным удалением
  локальных символов из неподписанной Chromium staging-копии до Developer ID
  signing. Локали, лицензии, notices, SwiftShader, crashpad и security evidence
  сохранены.

## Проверка выпуска

ZIP и DMG подписаны Developer ID, приняты Apple Notary Service, stapled и
проверены Gatekeeper. Точный tag commit:
`f436a66bd4f7e083fd8bf7b0cc56f0db448feb7f`.

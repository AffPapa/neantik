# Direct release 0.7.13 / 76

NeAntik 0.7.13 (76) — улучшения локального менеджера профилей.

- Штатная остановка браузера использует graceful quit, чтобы дать Chromium сохранить буферизованные persistent cookies и localStorage. Если закрытие не завершилось, менеджер сохраняет блокировку и предлагает повторить действие.
- Быстрые команды: Cmd-Shift-P, поиск профиля, показать открытый или запустить остановленный через обычные проверки.
- Пользовательские шаблоны с предварительным просмотром безопасных полей; каждый созданный профиль получает новую identity.
- Сохранённые фильтры и Undo безопасных metadata-действий (Cmd-Option-Z) с проверкой ревизии и конфликтов.
- Ограничение одновременной подготовки запусков, пауза новых запусков при memory pressure/thermal warning и локальный журнал последних 200 типов операций без приватного содержимого.

Chromium 154.0.8037.93 / ARM64 / Metal переиспользован без пересборки. Browser preferences и fingerprint policy не изменены. Safe Browsing отключён, защита Google Safe Browsing не предоставляется.

Ограничения: session cookies могут истекать при закрытии; перенос авторизации и session backup не обещаются. Metadata snapshots не являются резервной копией BrowserData. Batch UI, восстановление удаления и зашифрованный BrowserData backup отложены.

Проверки: 658 Swift tests; отдельный localhost fixture с существующим runtime для persistent cookies/localStorage/IndexedDB после закрытия и controlled crash; изолированный Dev.app GUI smoke. Физический VoiceOver не проверялся. ZIP и DMG прошли Developer ID signing, Apple notarization, stapling и Gatekeeper. Точный кандидат прошёл authenticated production A → B → A; автоматический выход manager потребовал timeout существующего wrapper. Первая неудачная попытка сохранена в evidence.

Rollback: v0.7.12, исходные опубликованные файлы сохраняются.

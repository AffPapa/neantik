# NeAntik 0.3.15 (18)

Публичный alpha-релиз для Mac с Apple Silicon. Менеджер нативный, Chromium
встроен в приложение; отдельная установка Chrome не нужна.

## Что изменилось

- NeAntik теперь всегда использует только встроенный проверенный браузерный
  движок. Старые ручные пути к Chrome/Chromium игнорируются.
- Поиск и теги не могут оставить скрытый профиль активным для запуска.
- Для существующих профилей заранее создаётся recovery-копия метаданных без
  изменения cookies или BrowserData.
- Создание профиля стало короче: имя, при необходимости прокси, затем
  «Создать». Иконка, цвет, теги и стартовая страница находятся в
  «Дополнительно».
- Недоступная проверка профиля показывает понятную причину, а иконки получили
  достаточный контраст.
- Менеджер примерно на секунду быстрее готов к работе, потому что большие
  Chromium hashes считаются только для защищённой fingerprint/release
  проверки.
- Локальная runtime-проверка ускорена примерно с 23,4 до 3,7 секунды.
- Одна постоянная release-команда теперь подходит для следующих версий без
  копирования version-specific скриптов.

## Установка

1. Скачайте DMG или ZIP из Assets ниже.
2. Для DMG откройте образ и перетащите `NeAntik.app` в `Applications`.
3. Для ZIP распакуйте архив и перенесите `NeAntik.app` в `Applications`.
4. Откройте NeAntik, создайте профиль, при необходимости настройте прокси и
   нажмите «Запустить».

## Системные требования

- macOS 14 или новее;
- Apple Silicon (ARM64);
- Chromium `150.0.7871.186`, Metal.

## Честные ограничения

Релиз предназначен для public-alpha изоляции профилей. Он не обещает полную
анонимность или «необнаружимость» и не предназначен для обхода CAPTCHA,
банов, антифрода или правил сторонних сервисов. Строгая production-
согласованность всех fingerprint- и сетевых поверхностей ещё не заявляется.

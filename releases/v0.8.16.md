## Удаление профилей WebKit

В этой версии профиль WebKit можно удалить из меню профиля. Окно объясняет, какие данные исчезнут, и предлагает архив, если профиль нужно только скрыть.

- Cookies, входы и данные сайтов удаляются штатным API macOS только у выбранного закрытого профиля.
- При прерывании остаётся запись операции. NeAntik блокирует повторное открытие удаляемого профиля и предлагает безопасно завершить удаление.
- Соседние профили сохраняют свои данные. Это проверено на точном подписанном приложении с отдельными тестовыми профилями.

NeAntik **0.8.16 (128)** — public alpha для macOS14+ и Apple Silicon. Chromium **156.0.8078.12** сохранён без пересборки. Формат существующих профилей и их identity не меняются. Завершённое удаление необратимо; старые версии не восстановят удалённые данные.

### Что пока недоступно в WebKit

Прокси, Chromium-расширения, полный backup сайтов, управление окнами через stdio MCP и полная подмена fingerprint пока не поддерживаются. WebKit использует параметры вашего Mac. Это не выпуск1.0 и не гарантия анонимности или обхода проверок сайтов.

ZIP/DMG предназначены для прямой установки. Контрольные суммы находятся в соседних `.sha256` файлах. Предыдущая0.8.15 сохранена для отката приложения; она не возвращает удалённые сайты.

# NeAntik 0.7.7 (70)

- Убраны ложные предупреждения: собственный запущенный профиль больше не считается занятым другим процессом.
- История успешного восстановления больше не требует повторного восстановления всех профилей.
- Исправлена VoiceOver-подпись следующего действия диагностики.
- Панель медиа явно обозначает временное тестовое окружение.

Chromium 153.0.8010.52 ARM64 / Metal сохранён без пересборки и изменения bytes. Это manager-only обновление public-alpha, не обновление безопасности Chromium и не заявление о полном fingerprint coherence.

Direct Distribution для Apple Silicon, macOS 14+. ZIP и DMG проходят Developer ID, Apple notarization, stapling и Gatekeeper перед публикацией. Контрольные суммы — в приложенных .sha256.

Предыдущий релиз 0.7.6 сохранён для rollback; Chromium и формат профильных данных не менялись.

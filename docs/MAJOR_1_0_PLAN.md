# NeAntik: план до версии 1.0

Текущий публичный выпуск — **0.8.2 (113)**, Chromium **156.0.8078.12**. Версия 1.0 ещё не готова. Исследование Fury сохранено; код его AGPL-компонентов в продукт не копируется.

## Очередь работ

1. **Быстрее разрабатывать.** Общие кэши, четыре CI-сегмента, точечный выбор тестов, защита от параллельной записи в кэш и компактные правила. Локальная проверка инструментов выполнена; время облачного CI ещё не измерено.
2. **Вкладки WebKit.** Новая вкладка, переключение, закрытие и ссылки, открывающие новое окно. Все вкладки одного профиля используют его хранилище. Данные разных профилей разделены. Это следующий законченный срез.
3. **Сеть и удобства WebKit.** Сначала отдельная проверка полномочий relay, DNS и WebRTC; затем загрузки файлов, восстановление вкладок, операции с данными и управление из MCP. До проверки прокси запуск такого профиля с прокси запрещён.
4. **Обязательные проверки 1.0.** Закрыть оставшиеся P0 из таблицы ниже, затем проверить данные, совместимость и обновление между актуальными выпусками.
5. **Дополнительные функции.** WireGuard и командная работа требуют отдельного решения об инфраструктуре. Финальная 1.0 выпускается только после обязательной квалификации.

Для продуктового среза: изменение → профильные тесты → реальные операции в браузере → подписанный кандидат → нотарификация и Gatekeeper → GitHub и сайт → проверка скачанных файлов. Инструменты разработки и документация проходят свои профильные проверки; новый бинарный выпуск для них не требуется. Пройденную проверку повторяем при изменении её входных данных, ошибке или конкретном оставшемся риске.

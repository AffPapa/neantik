# Обновление NeAntik: интерфейс и границы

Статус: **0.8.11 (122), public alpha**. Настоящие переход 0.8.10→0.8.11, перезапуск и откат проверены на отдельных тестовых профилях. Доказательства и ограничения — в [отчёте выпуска](../releases/v0.8.11.json). Исторические source-тесты не заменяют проверку новой пары версий.

## Как обновиться

1. Закрой браузерные окна и дождись завершения операций с профилями.
2. Нажми **Обновить NeAntik… → Проверить обновления**. Подпись описания и срок действия проверяются до показа новой версии.
3. Скачай оригинальный ZIP с [browser.free](https://browser.free/#install), затем нажми **Выбрать ZIP…**. Встроенный updater пока не скачивает архив сам.
4. После проверки файлов появится **Установить и перезапустить**. Нажатие разрешает установку; новый процесс должен подтвердить запуск. При отказе до подтверждения установщик возвращает прежнее приложение.

Вместо проверки канала можно выбрать ZIP и подписанный JSON manifest того же выпуска вручную. DMG и обычный файл SHA-256 не заменяют эти входы. Ручная установка DMG/ZIP в «Программы» также остаётся доступной. Данные профилей удалять не нужно; предыдущие release assets сохраняются.

## Границы проверки

Проверяются подпись Ed25519, срок описания, возрастающий build, macOS/architecture, hash ZIP, безопасная распаковка, Developer ID, runtime provenance, notarization и bootstrap. Название файла или успешное скачивание сами по себе ничего не подтверждают. При ошибке выбери оригинальные файлы выпуска и закрой другой менеджер.

Канал берётся из подписи установленного приложения. HTTPS retrieval ограничен разрешёнными адресами, 128 KiB и timeout; cookies, сохранённые сетевые пароли и кэш не используются. Старый `/api/update.json` сохраняет проверенный переход к 0.8.10; `/api/update-v2.json` предлагает 0.8.11 совместимым установленным клиентам.

Контроллер принадлежит приложению, держит admission fence до настоящего завершения операции и отмены. Закрытие sheet не означает завершение worker. При неизвестном результате cleanup требуется штатный выход. Согласие и исчезновение старого процесса не равны успешной установке: результат подтверждается commit/ACK и новой версией.

Native gate 0.8.10→0.8.11 использует два синтетических metadata-only профиля и mock Keychain. Он не доказывает перенос паролей между Mac, долговечность свежих cookies или работу на каждой версии macOS. Смена helper/runtime/media permissions требует новой квалификации. Сохранение подписанной предыдущей primary-пары описано в [workflow](DEVELOPMENT_WORKFLOW.md); изоляция QA — в [контракте](DIRECT_UPDATE_AUDIT_ISOLATION.md).

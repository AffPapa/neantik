# NeAntik: телеметрия и публичная статистика

## Текущий статус Direct

В Direct-сборке телеметрия **выключена**:

- `NeAntikTelemetryEndpoint` пуст;
- переключатель статистики скрыт;
- сетевые события не отправляются;
- постоянный идентификатор установки не создаётся;
- `Resources/PrivacyInfo.xcprivacy` объявляет отсутствие собираемых данных.

Это состояние обязательно сохраняется, пока одновременно не готовы сервер,
публичная политика конфиденциальности и проверенный release gate. Нельзя
показывать пользователю переключатель или публичную статистику раньше сервера.

## Контракт будущей Direct-телеметрии

Телеметрия может быть только добровольной и выключенной по умолчанию. Отказ не
ограничивает функции браузера. Payload версии 2 не содержит постоянного
идентификатора установки и допускает только:

| Поле | Назначение |
| --- | --- |
| `schemaVersion` | версия протокола |
| `eventID` | одноразовый случайный UUID события |
| `edition` | `direct` |
| `version`, `build` | версия NeAntik |
| `osMajor` | только основная версия macOS |
| `architecture` | всегда `arm64` |
| `profileCount` | общее число профилей с ограничением диапазона |
| `proxyProfileCount` | число профилей с включённым прокси |
| `event` | укрупнённое продуктовое событие |

Разрешённые события: первый запуск, снимок агрегированных счётчиков, создание
или удаление профиля, включение или отключение прокси, успешный или неуспешный
запуск браузера и обезличенный факт аварийного завершения менеджера.

Нельзя передавать:

- сайты, URL, историю, cookies и локальные данные страниц;
- имя, UUID, стартовую страницу, цвет или seed профиля;
- host, port, тип, login, password, IP, географию или часовой пояс прокси;
- Canvas, WebGL, Audio, GPU и результаты проверки отпечатка;
- Apple ID, email, серийные и аппаратные номера;
- постоянный или восстановимый идентификатор человека или установки;
- пути, содержимое буфера обмена, клавиши и полный crash report.

## Минимальная серверная архитектура

Сервер должен принимать только HTTPS JSON до 4 KiB, отклонять неизвестные поля
и не хранить IP в продуктовой базе. Одноразовый `eventID` разрешён лишь для
короткой дедупликации и удаляется не позднее 24 часов. Сырые события удаляются
после суточной агрегации; агрегаты по версии можно хранить до 90 дней.

Без постоянного идентификатора нельзя честно посчитать точные active installs
или crash-free users. До появления отдельно проверенной privacy-preserving
методики интерфейс и сайт должны называть доступные значения событиями, а не
людьми или установками. Скачать архив можно считать на стороне CDN отдельно от
приложения.

Публичная статистика публикуется только для выборки не меньше 25 событий или
установок в каждом срезе и округляется до ближайших 5. Маленькие версии,
редкие ошибки и сочетания признаков скрываются. Публичный API не должен
позволять вычитать соседние срезы и раскрывать малую группу.

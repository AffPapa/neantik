# Проверка голосового API Chromium

Это служебный стенд для пункта14 плана1.0, не настройка профиля и не новая
возможность синтеза речи. Старый результат availability/count сохраняется.

Новый стенд проверяет точный язык `navigator`, корректность языковых тегов
голосов, типы `default`/`localService`, один голос по умолчанию в текущем
Chromium, повторные чтения и доставку `voiceschanged`.
Имена голосов и `voiceURI` код проверки не считывает; речь не воспроизводится.
В результат входят только ограниченные счётчики, booleans и заданный тестовый
язык `en-US` или `fr-FR`.

## Что означает результат

- Нативное событие с непустым списком подтверждает доставку списка. При
  первоначальном `0 → непусто` дополнительно видна асинхронная загрузка.
- Первоначальная доставка не доказывает изменение установленных голосов.
- `dispatchEvent` проверяется отдельно и не может дать нативный PASS.
- Нет события, пустой список или недоступный API — `inconclusive`.
- Отсутствие установленного голоса нужного языка само по себе не ошибка:
  настройка языка профиля не фильтрует системный список голосов macOS.
- Проверка одного default относится к привязанному Chromium: его
  `SpeechSynthesisImpl::SendVoiceListToObserver` назначает `is_default = (i == 0)`.
  Она не объявляется общим требованием для WebKit.

## Запуск разработчиком

Быстрые контроли без браузера:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -B -m unittest scripts.tests.test_runtime_speech
```

Нативный запуск принимает только локальные абсолютные пути: скачанное
подписанное приложение, соответствующий публичный release JSON и новый
каталог результата. Например, после подстановки своих путей:

```bash
node scripts/runtime-speech/run-headed.mjs \
  /absolute/NeAntik.app /absolute/releases/v0.8.22.json \
  /absolute/new-voice-result configured en-US 21
```

Доступны `configured en-US 21`, `configured fr-FR 20` и контроль
`unconfigured fr-FR -`. Контроллер использует свой временный профиль,
mock Keychain, собственные loopback endpoints и ограниченный CDP pipe без
выполнения JavaScript или чтения cookies. При warning/critical/unknown
ресурсный допуск останавливает запуск. После штатного выхода проверяются
завершение процессов и удаление своего профиля; неподтверждённое владение
сохраняет каталог для разбора.

## Текущее состояние

14 JS-сценариев, включая отрицательные контроли oracle/pipe/cleanup,
и связанные Python-проверки прошли локально. Первая нативная подготовка
16 октября остановилась при memory pressure warning **до запуска браузера**.
Позже при normal admission прошёл один новый headed запуск точного скачанного
runtime0.8.22: configured `en-US`, корректные типы/default/locale, настоящее
событие первоначальной доставки, отдельное synthetic-событие и повторы.
Браузер вышел штатно с0; своих процессов и временного профиля не осталось.
[Минимизированный результат](evidence/speech-observation-0.8.22-partial.json)
не содержит списка или счётчика голосов.

Перед `fr-FR` pressure снова стал warning: браузер не запускался.
Остались этот случай, возврат `en-US` и unconfigured-контроль. Первый PASS
повторять не нужно. Пункт14 полностью не закрыт; продуктовый баг на этом этапе
не установлен. Смена установленного каталога голосов не проверена.

# Proxya Anty → NeAntik: проверяемый план переноса

Источник: https://github.com/ProxyaAnty/Proxya-Anty
Срез: `e12bc37c48b35453dcc426d091ad67a6f304959f`, 2026-09-06.

## Граница исследования

В публичном дереве находятся Node/Python SDK, MCP, документация,
скриншот и CI. React/Tauri/Rust-приложения, каталога устройств и Chromium
patches нет. Это прямо указано в CONTRIBUTING.md и BINARY-LICENSE.md.
MIT распространяется на опубликованные SDK/MCP, а не на закрытый движок.
Бинарники не запускались, зависимости не устанавливались, чужой движок
не переносился. Для полного исследования браузера нужен его private source.

## Рабочие роли

1. Архитектор: сопоставить реальные API и NeAntik, не выдавать клиентский
   метод за доказательство серверной реализации.
2. macOS UX-инженер: перенести иерархию скриншота в SwiftUI без Electron,
   с адаптацией к светлой теме, узкому окну, клавиатуре и VoiceOver.
3. Security reviewer: проверить границы API, отмену, секреты и лицензии;
   не переносить новые сетевые поверхности без отдельной модели угроз.

## Замечания по открытому коду

- `sdk/node/index.mjs`: fetch без deadline; waitJob timeout не ограничивает
  зависший HTTP-запрос. Произвольный baseUrl получает bearer token.
  Для переноса нужны проверка назначения и отмена самого запроса.
- `sdk/python/proxya_anty.py`: HTTP timeout 120 секунд есть, environment
  proxies отключены. Общий wait_job deadline всё равно не ограничивает
  длительность отдельного запроса. Ошибка stop временного профиля подавляется:
  завершение context manager не доказывает очистку.
- `mcp/index.js`: browser_evaluate повторяет исполнение после любой ошибки,
  включая исключение после побочного действия. Не применять такой retry.
  browser tools могут читать cookies и выполнять JS: это не безобидная
  библиотека отображения и не должно включаться незаметно.
- `sdk/node/cdpguard.mjs`: upgrade не проверяет случайный URL path или Origin;
  входной буфер и очередь не ограничены, ping/fragmentation не реализованы
  полноценно. Это основания для отказа от копирования транспорта, не
  доказательство взлома закрытого desktop-приложения.
- CI публичного дерева проверяет синтаксис/упаковку и npm audit, а не
  функциональность закрытого браузера. Заявленные detection PASS не
  перепроверялись и не являются гарантией анонимности.

## Проверка и границы публикации

Первый UI-проход не меняет хранилище, proxy credentials, fingerprint engine
или разрешения. Не добавляет runtime dependencies. Source UI contracts
проверяют правое положение запуска и сохранность существующих guard-условий.
Не считать рендер-тесты доказательством кликов в установленной программе.
Релиз и публичные download links этим проходом не изменяются.

Проверено локально: 751 Swift-тест / 76 suites после первого изменения;
после финального исправления titlebar и разделителей — 8 render tests и
29 responsive source contracts. Просмотрены изображения широкого тёмного
и минимального светлого окна, найденные наложение и перенос исправлены.
Это промежуточная UI-итерация, а не завершение всей матрицы выше.

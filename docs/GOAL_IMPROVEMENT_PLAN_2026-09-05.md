# NeAntik Goal: corrections, clarity and speed

Дата: 2026-09-05. База: `607c960`. Область: native manager. Три независимых аудита выполнены до изменений; доказательства — владельцы кода и текущие тесты. Уязвимости и ускорение без доказательств не заявляются.

## Цель первого этапа

Закрыть 12 выбранных исправлений/упрощений и 15 проверок. Остальные 13 пунктов — явная очередь либо отдельная поставка, не обещание выполнения всех крупных подсистем в этой цели. Новые данные профилей, runtime, зависимости, production установка и публичные артефакты защищены от изменений.

## Порядок и критерии

Доказательство → исправление → targeted tests → полный gate → UI/live → повторное review. Проблемы сохранения первыми. Параллельные владельцы: note/folder/undo; draft tag UX; batch/search computation. Корень ведёт план, интеграцию и проверку. При конфликте данных сохраняем пользовательский ввод. Не ослабляем тесты и release-гейты ради зелёного результата.

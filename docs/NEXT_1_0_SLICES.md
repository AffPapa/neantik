# Что остаётся до 1.0

База: опубликованная [0.8.13 (125)](../releases/v0.8.13.json).
Это public alpha, а не завершённая 1.0. Сохранённые проверки применяются к
указанным в них входам; список ниже не является заданием повторить их все.
Полная 45-пунктная приёмка остаётся в [major-плане](MAJOR_1_0_PLAN.md).

## Приоритетные законченные срезы

| Приоритет | Осталось | Что нужно сделать следующим |
|---|---|---|
| P0 | DNS и сетевые отказы (19–22) | Дополнить существующие HTTP/HTTPS/relay результаты независимым DNS-on-wire измерением, незакрытыми отказами и фоновыми запросами. Проверенные случаи не перезапускать без изменения runtime/маршрута. |
| P0 | Согласованность платформы (1–18, 40–43) | Сверить оставшиеся ограничения по когортам, HTTPS Client Hints и аппаратным условиям. Второй дисплей, другие Mac/macOS и реальные устройства — отдельные условия, а не повод повторять текущие Canvas/WebGL/Audio fixtures. |
| P1 — текущий | WebKit: сохранность вкладок (36) | Реализовано автосохранение, сериализация, окончательная запись и явные ошибки. Локальные проверки пройдены; новый оконный сценарий и будущий подписанный кандидат остаются открыты. Это не полный backup сайтов. |
| P1 | Восстановление данных (30–31, 35–36) | Доказать заявленное восстановление свежих cookies/IndexedDB/вкладок, ошибки и прерывания. Clone создаёт новую identity; restore сохраняет исходную. Не обещать перенос OS-encrypted секретов между Mac. |
| P1 | Расширения (33–34) | Завершить реальные install/disable/remove и CRX provenance по недостающим сценариям. Исследование и наличие кода не закрывают этот пункт. |
| P1 | Updater (37) | Следующие изменённые helpers, прерывания и другие macOS; существующие install/rollback и проверенную continuity не повторять для неизменённого кода. |
| P1 | Отчёты и документы (44–45) | Сравнивать совместимые реальные измерения между версиями, поддерживать фактические capability/release claims. Отчёт сам по себе не является runtime-проверкой. |

## Что ещё нужно WebKit

| Возможность | Фактическое состояние | Условие следующего шага |
|---|---|---|
| Отдельные данные, вкладки, загрузки, HTTP-кэш | Есть в опубликованных версиях; результаты ограничены указанными ОС/fixtures | Сохранять существующие evidence; проверять только изменяемую поверхность. |
| Автосохранение вкладок | Новая локальная реализация после 0.8.13 | Новый оконный сценарий, ошибки/порядок записей, затем квалификация будущего кандидата. |
| Прокси | Запуск с прокси отклоняется, Direct fallback запрещён | Отдельный путь WKWebsiteDataStore + per-profile relay; browser HTTP/HTTPS/DNS/UDP, отказ upstream и владение системными WebKit-процессами. Не расширять полномочия relay на все Apple-процессы или общий UID. |
| Запуск/остановка через MCP | Создание/редактирование есть; stdio GUI launch отклоняется | Аутентифицированный локальный IPC к GUI с явными правами/профилем/сессией и проверкой закрытия. Снятие текущего запрета не является реализацией. |
| Камера и микрофон | Policy-код есть, в поставке выключены | Реальный capture, отказ/отзыв и изоляция разрешений на точном подписанном кандидате. |
| Удаление профиля | Архивирование есть; удаление данных запрещено | Public WebKit removal API, закрытый профиль, журнал прерываний/ошибок и согласование metadata. Не удалять внутренние папки WebKit вручную. |
| Полный backup | Нет; metadata export не переносит сайты | Поддерживаемый согласованный snapshot/restore, целостность, защита распаковки и проверенная переносимость. |
| Расширения | Chromium-расширения не применяются | Отдельное исследование поддерживаемых системным WebKit API; не обещать Chrome/Safari extension compatibility. |
| Настройка fingerprint | Системная идентичность macOS, не Chromium-политика | Отдельное исследование собственного WebKit runtime. Подмена UA или JS-полей не даёт согласованной реализации Safari. |

WireGuard на профиль и team mode имеют принятые исследовательские решения об
отсрочке: [условия возврата](OPTIONAL_NETWORK_TEAM_DECISIONS.md). Повторять эти
исследования по умолчанию не нужно. Trusted HTTPS-upstream positive отложен
пользователем до появления подходящего тестового сервера.

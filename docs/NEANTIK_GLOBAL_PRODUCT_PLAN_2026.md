# NeAntik product plan 2026

> Current public release: 0.9.3/build 203 public alpha; Chromium 156.0.8078.80. Source of truth: `releases/v0.9.3.json`. WebKit is deferred; major1.0 remains open.

## 1.0 delivery gates

1. Qualify the exact bundled Chromium and owned-WebKit candidate for Direct Distribution.
2. Prove WebKit page loading, per-profile proxy routing, fail-closed behavior, recovery, and profile isolation.
3. Publish matching source, applicable licenses, notices, and a recipient relink path.
4. Measure privacy behavior and state its limits; do not promise anonymity or bypass of site controls.
5. Sign, notarize, staple, and verify Apple Silicon ZIP/DMG; publish through GitHub Releases and browser.free; verify downloaded bytes.

The public acceptance checklist is [NEXT_1_0_SLICES.md](NEXT_1_0_SLICES.md). Private candidate identity and live execution state are maintained outside public source archives. This plan does not claim a 1.0 release or set a date.

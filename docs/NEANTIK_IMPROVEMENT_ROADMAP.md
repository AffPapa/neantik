# NeAntik improvement roadmap

> Current public release: 0.9.1/build 201 public alpha; Chromium 156.0.8078.80. Source of truth: `releases/v0.9.1.json`. WebKit is deferred; major1.0 remains open.

## Release 1.0

- Qualify bundled Chromium and owned WebKit on the exact Direct Distribution candidate.
- Prove WebKit page load, profile proxy routing, fail-closed behavior, and recovery.
- Close source, license, notice, and recipient relink obligations for shipped runtime bytes.
- Verify privacy and profile isolation with evidence; make no anonymity or anti-fraud-bypass claims.
- Sign, notarize, staple, and verify ZIP/DMG; publish on GitHub and browser.free; verify downloaded bytes.

See the public [acceptance plan](NEXT_1_0_SLICES.md). This page does not claim that 1.0 has shipped or promise a release date.

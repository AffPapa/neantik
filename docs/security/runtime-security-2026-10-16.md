## Исправления безопасности Chromium — 16 октября 2026

В исходниках поставляемого Chromium 156.0.8078.12 отсутствует upstream-исправление DOM **CVE-2026-110913**. Это результат сопоставления исходников с зафиксированным runtime; эксплуатация уязвимости не выполнялась. Подпись Apple и прежние проверки изоляции не устраняют этот пробел.

0.8.19 (131) собрана и нотарифицирована локально, но **не опубликована**. Публичные файлы 0.8.18 сохранены. До исправления runtime не рекомендуем использовать эту Chromium-сборку для недоверенных сайтов. Окна на системном WebKit относятся к отдельному движку macOS и не получают гарантий безопасности из этой проверки.

Причина ошибочного допуска: правило сравнивало номера разных веток — 156 выше 155. Однако исправление в ветке Stable 155 не обязательно уже входит в более раннюю сборку 156. Новое правило требует для другой ветки полный разбор опубликованного набора исправлений, привязанный к точным commit и source contract. Альфа-статус не отменяет проверку. Release doctor, подготовка и нотарификация используют это ограничение.

Отрицательные контроли подтверждают отказ для текущего реального lock в обоих режимах. Список fixes дополнительно сопоставляется с ссылками официального security post. Ссылки на изменяемую ветку, корень домена и один лишь анонс релиза не принимаются за доказательство включения fix.

Простой переход на 156.0.8078.39 также недостаточен: в проверенных исходниках отсутствуют полные Prerender, Core и Workers corrections; Compositing подтверждён частично, Desktop остаётся неустановленным. Следующий runtime должен включить необходимые upstream corrections/backports и пройти относящиеся к изменению проверки. Смена номера не закрывает задачу.

- [Официальный security batch Chrome](https://chromereleases.googleblog.com/2026/10/stable-channel-update-for-desktop_01886704284.html).
- [Upstream DOM fix, точный commit](https://chromium.googlesource.com/chromium/src/+/6f8bd0510049073dacc94db8968ba350678da324).
- [Машиночитаемый scope и проверки](../evidence/runtime-security-development.json).
- [Оставшиеся задачи до 1.0](../NEXT_1_0_SLICES.md).

Новый guard исправляет выпуск, а не сам Chromium. Предыдущие PASS сохранены для своих входов; они не выдаются за квалификацию нового security batch.

## Выполняемое исправление

Восемь недостающих upstream patches перенесены целиком в собственное дерево исходников; все35 изменённых путей сверены после применения. В исходном production-коде уже были corrections Desktop и Compositing, поэтому они не применяются повторно. [Патчи, BSD-лицензии и точный manifest](../../runtime/security-backports-20261015/README.md) открыты. Для Core взят официальный M156 backport вместо конфликтующего main patch.

Старые файлы сохранены до изменения. Готовится отдельный COW output с прежними патчами, toolchain и кэшем. Это ещё не пересобранный runtime: проверки поведения и выпуск остаются открытыми, security guard по-прежнему блокирует публикацию. Номер Chromium не меняется ради видимости обновления.

# Перенос конфигурации профилей

NeAntik поддерживает два manager-only формата переноса:

- обычный JSON для локального обмена без пароля;
- зашифрованный JSON-файл для переноса между устройствами.

Оба формата содержат только настройки профиля и имя папки. В них не входят
Cookies, BrowserData, local storage, заметки, identity, fingerprint evidence
или значения Keychain. Импорт всегда создаёт новые идентификаторы профилей и
новую identity; существующая браузерная сессия не клонируется.

Зашифрованный формат использует AES-256-GCM с отдельными случайными 16-byte
salt и 12-byte nonce. Ключ выводится из введённого пользователем пароля через
PBKDF2-HMAC-SHA256 с фиксированными 600 000 итерациями. Envelope проверяет
версию схемы, алгоритмы, размеры и base64-поля до расшифровки; ошибка пароля,
повреждение ciphertext и неподдерживаемая схема завершаются без импорта.

Пароль не записывается в файл, настройки приложения или Keychain. Минимальная
длина — 12 UTF-8 bytes; приложение не восстанавливает и не предлагает пароль.
Потерянный пароль не восстанавливается. Размер plaintext ограничен 16 MiB,
размер encrypted envelope — 24 MiB.

Это перенос конфигурации, а не backup. Для восстановления BrowserData или
Keychain-секретов этот формат намеренно не предназначен.
